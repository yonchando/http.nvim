## Project state

http.nvim is a Neovim plugin (pure Lua, LuaJIT) for sending HTTP requests from `.http` files and viewing JSON responses. The `v2` branch is a **rewrite in progress**: the v1 implementation (Go helper binary + `cmd.lua`/`ui.lua`/`log.lua`/`floating/window.lua`, `plugin/load_http.lua`) has been removed from the working tree but is still available in git history (`git show HEAD:<path>`, or the `main` branch) for reference. `README.md` still documents v1 behavior and commands (`:HttpRun`, `:HttpResult`, `:HttpRerun`, `:HttpClose`, `:HttpHistory`), which v2 does not register yet.

### v1 architecture (for reference)
- `plugin/load_http.lua` registered user commands that called into `require("http-nvim")`.
- `init.lua` used `vim.treesitter.get_node()` and walked up to the enclosing `request` node of the tree-sitter `http` grammar to find the request under the cursor.
- `cmd.lua` extracted method/url/headers/body from that node, built a command line, and ran it asynchronously; the Go binary (`main.go`/`http.go`, args `--url --method --data --header`) performed the request with curl-like behavior and printed a JSON envelope (`status_code`, `header`, `request`, `body`).
- `ui.lua` rendered the result in a floating window; module-level `state` held the last request/response and history.

### v2 architecture (current)
- `plugin/http.lua` — auto-loaded entrypoint: maps `<leader>rr` to `require("http-nvim").open()` and runs `helptags` on VimEnter for a hardcoded path (`stdpath("data")/site/pack/chando/start/http.nvim/doc`).
- `lua/http-nvim/init.lua` — opens a [nui.nvim](https://github.com/MunifTanjim/nui.nvim) `Split` panel (dependency: `nui.split`), with `g?` opening `:help http-nvim`. `setup(opts)` is a stub. State is kept in a module-local `state` table.
- `doc/http-nvim.txt` — vim help file (keep in sync with commands/keymaps; `doc/tags` is generated by `:helptags`).

## Development

There is no build step, test suite, or linter config beyond `.luarc.json` (lua-language-server: LuaJIT runtime, `vim` global, strict table shapes). Runtime requirements: Neovim with the tree-sitter `http` parser (`:TSInstall http`), `curl`, and `nui.nvim`.

To try the plugin locally without a plugin manager:

```sh
nvim --cmd "set rtp+=." --cmd "set rtp+=/path/to/nui.nvim" test.http
```

`*.http` files are gitignored, so scratch request files can live in the repo root.

2. KEYMAPS                                             *http-nvim-keymaps*

<leader>rr                  open your collection resapi.
g?                  Open this help page.
<CR> or =           Expand or collapse the collection or folder under the
                    cursor.
e                   Edit the request under the cursor in JetBrains HTTP
                    Client format, in a new split above the panel.
                    Closing that window returns to the panel.
                    |:w| saves the request and rewrites the collection
                    JSON file (keys sorted, 4-space indent). Only the
                    first `### name` section is kept; other sections are
                    removed from the buffer. Changing the `### name` line
                    renames the request.
a                   Add a request or folder: inside the folder under the
                    cursor, next to the request under the cursor, or at
                    the top level on any other line.
                    `get-users` adds a request and opens it for editing.
                    It starts as `GET` with an empty URL; fill in the URL
                    before |:w|.
                    `api/v1/get-users` adds the request inside folders
                    `api/v1`.
                    `api/v1/` (ending with `/`) adds only the folders.
                    Folders that already exist along the path are reused.

3. HIGHLIGHTS                                       *http-nvim-highlights*

The panel buffer (filetype `http-nvim`) defines these groups, styled after
vim-fugitive. Override any of them with |:highlight|.

  httpNvimHeader       Header label, e.g. `Env:`        links to |hl-Label|
  httpNvimHelpHeader   The `Help:` label               links to httpNvimHeader
  httpNvimHelpTag      Key after `Help:`, e.g. `g?`      links to Tag
  httpNvimHeading      Section heading                 links to PreProc
  httpNvimCount        Section count, the `N` in `(N)`   links to Number
  httpNvimEntry        Entry key in `KEY = value`       links to Identifier
  httpNvimEquals       The `=` in an entry              links to Operator
  httpNvimValue        Entry value                     links to String
  httpNvimItemCount    Item count, the `N` in `(N) name` links to httpNvimCount
  httpNvimItem         Item name, e.g. a collection    links to |hl-Directory|
  httpNvimFold         Expand/collapse marker `▸`/`▾`    links to Special
  httpNvimMethod       Request method, e.g. `GET`       links to Keyword
  httpNvimRequest      Request name                    not linked
